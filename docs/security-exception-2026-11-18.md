# Временное исключение для зависимости сборки

Владелец 18.11.2026 явно разрешил исключение только для GHSA-fc5q-39xc-vjpf до 25.11.2026. Срок в проверке: **25 ноября 2026, 00:00 UTC**, без автоматического продления.

На дату проверки исправленной опубликованной версии picomatch нет. Уязвимость относится к обработке специально подобранных glob-выражений. picomatch, его посредники и Vite/Vitest в данном lock-файле являются только dev-зависимостями. Сборка работает с исходниками доверенного репозитория; пользовательские glob-выражения в неё не поступают. Рабочий frontend отдаётся как статические файлы; эти Node-инструменты не работают на пользовательских запросах. `npm audit --omit=dev --audit-level=moderate` проходит.

`scripts/audit_frontend.py` выполняет настоящий npm audit и разрешает только граф зависимостей, где каждый конечный advisory равен этому GHSA, а каждый затронутый узел отмечен `dev: true` в lock-файле. Другие уязвимости, runtime-зависимость, неизвестный граф, сбой audit или истечение срока блокируют выпуск. Проверка не объявляет уязвимость устранённой. Есть проверки отказа для каждого из этих случаев.

После публикации upstream-исправления обновить зависимость, удалить исключение и вернуть прямой audit без исключений. Уязвимость Go GO-2026-6859 исключением не покрывается: для неё применяется Go 1.27.4.
