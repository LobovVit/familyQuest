# Проверка FamilyQuest — 19 сентября 2026

Проверены исходники backend/frontend, SQL-миграции, Docker/Compose/Nginx, CI, конфигурация и Markdown-документация. По подтверждению владельца в общий результат включены параллельные изменения раздела «Семья». Проверка проводилась локально на отдельных тестовых PostgreSQL; работающий домашний сервис не изменялся.

Проверены уязвимости зависимостей: исправлены выявленные `pgx`, `x/text`, `nanoid` и `postcss`; обновлён `x/crypto`. Проверки уязвимостей отражают состояние баз advisories на момент запуска и не являются гарантией отсутствия неизвестных проблем.

## Архитектурная оценка

Направление зависимостей Clean Architecture восстановлено для основных application/domain слоёв и закреплено автоматическими проверками. Сохранены рабочие сценарии и форма существующих API; правила и компромиссы явно описаны в [архитектуре](architecture.md).

Оставшиеся ограничения: один семейный контур на установку, публичные имена/рейтинги, отсутствие пагинации и отдельного медиахранилища, ленивое создание задач при GET, расчёт исторических рейтингов из текущего каталога, широкий Repository и React hooks в application. Это не заявляется как полностью независимая от фреймворков реализация Clean Architecture.

## Метод проверки

Home Local AI использован для независимого анализа. Конкретные выводы проверены чтением кода и тестами; неверные общие советы о Promise.all, localStorage и SQL-транзакциях не применялись.

Проверки перед публикацией включают Go unit/integration/race, go vet, границы зависимостей, frontend DOM/unit/lint/build, npm audit, govulncheck, Docker-сборки, запуск контейнеров с read-only filesystem, HTTP smoke и ссылки документации.

## Подтверждённые результаты

- Frontend: 28 тестов в 8 файлах, lint без предупреждений, production build. Проверены все 7 Markdown-документов, битых локальных ссылок нет.
- Backend: unit и PostgreSQL integration tests с `-race`, включая конкурирующие миграции и удаления взрослых; `go vet`.
- Браузер: вход взрослого, библиотека → приключение → перезагрузка → три выполненных шага → сад; привычка со временем 20:30 и облегчённой отметкой; сохранение договорённости семейного совета; экран 390 px без горизонтального переполнения. Медиа и согласование ребёнка проверены серверными тестами, отдельно вручную в UI не проверялись.
- Контейнеры: API и web собираются и запускаются не от root с read-only filesystem и сброшенными capabilities; `nginx -t` проходит.
- На пустой БД production-образ возвращает пустой список участников и не содержит `/app/seed`; явный синтетический bootstrap работает.
- HTTP через Nginx: вход, RBAC, автор из JWT, запрет pending-confirmation, weekly complete/confirm, семейная карточка, отзыв JWT после PIN/restore, JSON-import 21 MiB, ограничение входа 429 — успешно.
- `npm audit`: 0 уязвимостей. `govulncheck` исходников и бинарника из Docker: 0 затронутых используемых пакетов. Единственное module-only уведомление относится к неиспользуемому `golang.org/x/crypto/openpgp`, для которого исправления нет; приложение использует bcrypt, не OpenPGP.

Production-сервис, VPN и внешняя инфраструктура не изменялись. Полное восстановление PostgreSQL dump на новом сервере, внешняя доставка календарных уведомлений и многочасовые нагрузочные испытания не выполнялись.
