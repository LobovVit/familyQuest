# История версий

## 0.1.4 — 2026-09-27

Переключатель видимости пароля заменён иконкой глаза внутри поля. Сохранены доступное название, состояние переключателя и управление с клавиатуры.

## 0.1.3 — 2026-09-27

Исправлена отправка формы взрослого аккаунта при автозаполнении без событий React: фактические значения читаются из формы. Добавлены показ пароля и пояснение отличия пароля аккаунта от PIN профиля. Регрессия воспроизведена тестом (раньше отправлялись пустые строки). Пароли и правила их проверки не меняются.

## 0.1.2 — 2026-09-27

После checkout явно загружается tag object и проверяется его соответствие SHA события. Это устраняет повторную подмену локальной ссылки на commit внутри actions/checkout даже при fetch-depth: 0.

## 0.1.1 — 2026-09-27 (тег не прошёл release CI)

Исправлена загрузка аннотированных тегов в CI: контейнерная проверка получает полную историю и настоящие объекты тегов, а не shallow-ссылку на commit. Полной истории оказалось недостаточно: checkout повторно заменил локальную ссылку тега на commit.

## 0.1.0 — 2026-09-27 (тег не прошёл release CI)

Первый маркированный релиз. Сохраняет домашний режим и включает опциональный закрытый SaaS-пилот: изоляцию семей, возрастные настройки обучения, операторское подключение и учёт подписки с лимитом детей, backup v6, чтение и награды.

Добавлены встроенные метаданные сборки, `/api/version`, раздел «О приложении», аннотированные теги и GitHub Releases после CI, установка конкретного тега с проверкой запущенной версии. Самостоятельная регистрация и платёжный провайдер пока не включены. Обновление не переключает домашнюю установку в SaaS.

Изменения до этой версии не имели продуктовых тегов; их история сохранена в Git.
